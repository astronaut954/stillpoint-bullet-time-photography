- Save sessions: Photos, Sequence and the new Lenticular are now outputs you can combine. Tick any of them (each opens its settings; unticked ones stay folded) and one Save writes everything, each session in one folder with Photos/, Sequence/ and Lenticular/ inside. The window opens directly, without the Photos / Sequence choice first. Each section can be folded with the arrow on its header
- Photos: keep the originals, save a converted copy (JPG, PNG, WEBP, TIFF, HEIC), or both at once, each in its own folder
- Lenticular print (first part): a new Lenticular output turns a session into one interlaced TIFF to print under a lenticular lens sheet. Pick the lens (40–100 LPI, or type yours), the printer's native dpi (600/720/1200/1440 or other), the print size (cm or inches, presets) and the effect (animation when tilting, or 3D); the window shows the columns per lens, dots per photo and warns when the combination cannot separate the photos. Drag the preview left and right to see the photos change, or switch it to "Interlaced" to see a 1:1 crop of the file itself. The TIFF carries the dpi so it prints at the exact size (print at 100%, never "fit to page")
