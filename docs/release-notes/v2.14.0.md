- Save sessions: Photos, Sequence and the new Lenticular are outputs you can combine. Tick any of them and one Save writes everything, each session in one folder with a subfolder per output
- Photos: keep the originals, save a converted copy (JPG, PNG, WEBP, TIFF, HEIC), or both
- Lenticular print: turns a session into one interlaced TIFF to print under a lenticular lens sheet (animation when tilting, or 3D). Previews of the effect and of the file itself, crop marks, alignment marks and bleed, and the settings saved next to the file
- Lenticular pitch test: a test sheet to find the real LPI of your lens sheet with your printer. Open it from the lens icon on the main screen or from the Save window
- Save sessions saves straight to an Exports folder (the project's, or Pictures/Stillpoint/Exports); "Choose another folder…" changes it for one save
- Right-click a photo: Show in Finder / Explorer, Open in default app, Delete photo
- Keyboard: Tab and the arrow keys reach every control, in the main screen and in every window; Enter ticks boxes and picks options
- Undo now also covers Camera settings changes (one step for Match automatically), the Save window settings, the pitch test, Close project and New project
- Live: both Live windows can open the other one; on Mac, Cmd+` switches between the main window and the Live windows
- Smoother screen: animations when panels open and close, when cameras change places and when photos and sessions are deleted
- Settings → Opening: turn off the logo animation when the app opens
- Fixed: closing Camera settings during a Test shot or a chart calibration now cancels it (the app could stay stuck on "Receiving photos")
