- Trash: deleted sessions and photos now stay in a trash for 15 days instead of being deleted for good. Open it with the trash button next to the project menu to restore or delete each item, or empty it; it shows how much space it takes
- Delete a project from the project menu or the Project window: the whole folder goes to the Trash, on the same disk, and can be restored
- Sessions of a project go to a trash inside the project folder, on the same disk, so deleting from an external drive is instant and does not use space on the computer
- Select several sessions with Cmd/Ctrl+click and Shift+click, then right-click, press Delete or drag them together to the project button, to "Not in project" or to the trash. "Delete…" in the Project window does the same. One Undo brings them all back
- Drag a session or a photo to the trash button to delete it; Undo brings it back
- Drag photos sideways to change their order right away, one or several at a time (Shift+click or Cmd/Ctrl+click), also in Reorder and Reorder by photo. The photos slide into place, and Undo puts the order back, in Reorder by photo even before you save
- Full screen: a slim bar on the left shows every session as an icon, with its name as soon as you point at it; the top button shows the names
- Top bar: nothing wraps when the window is narrow; the least important details hide first, and big numbers are shortened (1.3k, 1.3 TB). A long project name is shortened too (the full name appears when you point at it)
- "Save sessions" is now "Export sessions"
- Sessions have their own icon, so they no longer look like the project
- The Timing tag is green; it turns yellow only when the timing has a problem
- Esc closes Activity
- Fixed: "A session with this name already exists" when adding a session back to a project, after removing it while its photos were still loading
- Fixed: Cmd/Ctrl+click in the session list could mark sessions that were not clicked
- Fixed: on Mac, pressing F for full screen (or any letter outside a text field) made the system error sound
- Fixed: the full-screen title showed the seconds twice
