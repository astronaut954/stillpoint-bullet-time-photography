- Projects now keep the rig: the Bullet time panel (Countdown, Sessions, Download wait, Timing), the camera order and the settings of each camera. Opening or switching a project brings them back
- When the cameras are not as the project left them, Stillpoint shows what differs and asks before changing anything: "Keep the cameras as they are" or "Apply the project settings". Both can be undone
- A camera of the project that is not connected, or a new one, only shows a warning; nothing is blocked
- With no project open, the Bullet time panel starts from the default values and nothing is saved
- The Activity bar stays visible with a window open (Export sessions, Camera settings, Project, Trash, Settings); click it to open the list over the window. In session fullscreen it slides up when the mouse reaches the bottom edge
